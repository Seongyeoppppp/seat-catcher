# 좌석잡이 (SeatCatcher)

코레일 앱 조회 결과 화면에서 **정해둔 출발 시간대 + 등급에 가격이 뜨면(=좌석)** 대신 눌러서
**바로 예매**까지 하고, 성공하면 알람 소리와 함께 알림을 보냅니다. 결제는 직접 하면 됩니다.

## 빌드 (Android Studio)
1. 이 폴더를 Android Studio에서 `Open` → Gradle Sync가 끝날 때까지 기다리기
2. 폰을 USB로 연결 (개발자 옵션 → USB 디버깅 ON) → ▶ Run
   - `Build > Build APK(s)`로 APK만 뽑아서 폰에 설치해도 됩니다.

## 처음 한 번 설정
1. 앱 열기 → **① 접근성 권한 켜기** → 설치된 앱 → 좌석잡이 → 사용
   - 회색으로 막혀 있으면: 설정 → 애플리케이션 → 좌석잡이 → 오른쪽 위 ⋮ → **제한된 설정 허용** 후 다시
2. **② 알림 권한 허용** → **🔔 알림 테스트**로 소리, 진동이 오는지 확인
3. 삼성 배터리 설정: 애플리케이션 → 좌석잡이 → 배터리 → **제한 없음**
4. (추천) 개발자 옵션 → **충전 중 화면 켜짐 유지** ON

## 쓰는 법
1. 코레일 앱에서 날짜·출발역·도착역·시간을 정해서 **조회** (원하는 시간대가 목록에 보이게)
2. 좌석잡이에서 출발 시각 범위, 등급, 새로고침 간격을 입력 → **▶ 저장하고 시작**
3. 코레일 화면이 뜨고, 맨 위에 검은 상태바(🚄 좌석잡이 …)가 보이면 동작 중이에요
   - 상태바를 탭하면 중지돼요
4. 성공하면 알람이 울려요 → 알림을 누르면 코레일 앱으로 → **결제기한 안에 결제**

## 다른 알림이 와도 안전한 이유
- 화면 좌표가 아니라 **코레일 앱 안의 버튼에 직접 클릭 명령**을 보내요. 알림 배너가 위에 떠 있어도 배너는 눌리지 않아요.
- 맨 앞 앱이 코레일이 아니게 되면(카톡을 눌러서 열었거나 전화가 온 경우 등) **아무것도 누르지 않고 일시정지**해요. 코레일로 돌아오면 다시 이어서 해요.
- 알림창을 내려두면 일시정지해요.
- 버튼을 직접 누를 수 없어서 좌표 탭을 써야 할 때는, 그 자리를 다른 창이 덮고 있으면 **탭하지 않아요**.

## 안전장치
- 새로고침 간격은 최소 2초이고, 실제 간격은 ±랜덤으로 정해져요 (기본 2초)
- 한 번 예매에 성공하면 자동으로 멈춰요 (1회 실행에 1장)
- 연속으로 15번 놓치거나 최대 실행 시간이 지나도 멈춰요
- 입석+좌석, 매진은 절대 누르지 않아요 (가격이 뜬 칸만 눌러요)

## 인식이 안 될 때
코레일 앱이 업데이트되면 화면 구조가 바뀔 수 있어요. 이럴 땐:
1. **코레일 화면 구조 저장 (3초 뒤)** → 조회 결과 화면을 띄운 채로 3초 기다리기
2. 좌석잡이로 돌아와서 **저장된 화면 구조 복사** → Claude에게 붙여넣기
   → 덤프 맨 아래 `인식 결과`를 보면 어디서 막혔는지 바로 알 수 있어요.

> ⚠️ 코레일은 매크로 탐지를 하고 있어서, 걸리면 예매가 제한되거나(1회 30분, 2회 1개월) 3회째엔 멤버십에서 탈퇴될 수 있어요. 간격은 너무 짧게 잡지 마세요.
